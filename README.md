# Tic Tac Toe

Two-player tic-tac-toe, built with OOP. Click to place your X or O, hit reset for a fresh board, and the game announces the winner right in the page.

![Tic Tac Toe screenshot](screenshot.png)

The hardest part is the win detection. After every move, the code has to check all 8 winning lines without missing one, and do it cleanly through objects instead of a pile of if statements.

HTML, CSS, and JavaScript.
